# Dynamic Facial Framing

A Python library for converting horizontal videos to vertical (9:16) format with intelligent face tracking and dynamic framing. The system automatically detects faces in videos and dynamically adjusts the crop to keep the speaker centered as they move.

## Features

- **Dynamic Face Tracking**: Automatically detects and tracks faces across video frames
- **Smooth Framing**: Uses exponential moving average for smooth crop transitions
- **Multiple Layout Modes**: 
  - Face-centered vertical crop
  - Blurred background with foreground rectangle
  - Gameplay background overlay
  - Simple cover crop
- **Segment-based Processing**: Processes video in small segments for true dynamic cropping
- **Flexible Face Detection**: Supports MediaPipe (recommended) or OpenCV DNN/Haar Cascade

## Usage

### Basic Example

```python
from app.vertical import extract_dynamic_layout
from app.layout.state_machine import LayoutStateMachine
import cv2

# Initialize state machine
state_machine = LayoutStateMachine()

# Extract dynamic layout with face tracking
result = extract_dynamic_layout(
    src="input_video.mp4",
    dst="output_video.mp4",
    start=0.0,
    duration=60.0,
    state_machine=state_machine,
    background_mode="blur"
)

if result["success"]:
    print(f"✅ Video processed successfully!")
    print(f"Dominant layout: {result['dominant_state']}")
    print(f"Face tracks: {len(result.get('face_tracks', []))}")
else:
    print("❌ Processing failed")
```

### Simple Vertical Conversion

### Dynamic Facial Framing

```python
from app.vertical import extract_dynamic_facial_framing
from app.vertical import get_video_dimensions

# Get video dimensions
width, height = get_video_dimensions("input.mp4")

# Face tracks (typically generated by LayoutStateMachine)
face_tracks = [
    {"frame": 0, "bbox": [500, 300, 200, 250], "confidence": 0.9},
    {"frame": 30, "bbox": [520, 310, 200, 250], "confidence": 0.9},
    # ... more face tracks
]

# Extract with dynamic framing
extract_dynamic_facial_framing(
    src="input.mp4",
    dst="output.mp4",
    start=0.0,
    duration=30.0,
    face_tracks=face_tracks,
    source_width=width,
    source_height=height
)
```

## Configuration

Edit `app/settings.py` to customize behavior:

```python
# Face detection settings
face_detection_model: str = "mediapipe"  # "mediapipe" or "opencv_dnn"
face_detection_confidence: float = 0.5
face_tracking_smoothing: float = 0.7  # Higher = smoother

# Crop settings
crop_smoothing_factor: float = 0.15  # How quickly crop follows face (0-1)
min_face_size: int = 100  # Minimum face size in pixels
crop_padding: float = 1.5  # Padding around face

# Output settings
vertical_width: int = 1080
vertical_height: int = 1920
output_fps: int = 30
```

## How It Works

1. **Face Detection**: The system detects faces in each frame using MediaPipe or OpenCV
2. **Face Tracking**: Faces are tracked across frames using IoU (Intersection over Union) matching
3. **Crop Position Calculation**: For each frame, the system calculates the optimal crop position to center the face
4. **Smooth Interpolation**: Crop positions are smoothed using exponential moving average to avoid jittery movements
5. **Segment Processing**: The video is processed in small segments (0.33 seconds) with different crop positions
6. **Concatenation**: Segments are concatenated to create the final video with smooth dynamic framing

## Layout States

The system uses a state machine to determine the best layout:

- **VERT_FOCUS**: Face-centered vertical crop (used when face is consistently detected)
- **BG_BLUR_RECT**: Blurred background with foreground rectangle (used when no face is detected)
- **GAMEPLAY**: Gameplay background overlay (used when background_mode="gameplay")
- **COVER**: Simple cover crop (fallback)

## Troubleshooting

### FFmpeg not found
Make sure FFmpeg is installed and available in your PATH. Test with:
```bash
ffmpeg -version
```

### MediaPipe not available
If MediaPipe installation fails, the system will fall back to OpenCV Haar Cascade. For better results, install MediaPipe:
```bash
pip install mediapipe
```

### Face detection not working
- Check that faces are visible and large enough (min_face_size setting)
- Adjust face_detection_confidence in settings
- Try different face_detection_model ("mediapipe" or "opencv_dnn")

### Video processing is slow
- Reduce segment_duration (currently 0.33 seconds) for faster processing but less smooth transitions
- Use faster FFmpeg preset (change in settings)
- Process shorter video clips
